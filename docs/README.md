# The docs

Two kinds of doc live here. **Guides** explain how something works or how to make something, and
are kept current. **Working notes** are how the game was planned and built: plans, decisions and
where things stood, written as we went. They're kept as the record, not tidied after.

In the working notes, "the owner" is the person who makes the calls on racecar, and a quote with a
date is their ask or decision on that day: the notes keep the reasons next to the code they shaped.
Status lines and "next" lists in them can be out of date; the [CHANGELOG](../CHANGELOG.md) and
[HANDOFF](./HANDOFF.md) are the current word.
